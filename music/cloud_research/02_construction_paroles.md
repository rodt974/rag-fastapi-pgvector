## NOTE PRÉLIMINAIRE : Willylancien est une IA

Willylancien ("Magique", "Tempête", EP *Demain c'est vide*, avril 2026) est un projet entièrement généré par IA, identifié sans ambiguïté par Deezer. Le projet a accumulé 1,5 M de streams en 10 jours et atteint le top 74 Spotify France — **preuve que les patterns décryptés ici sont suffisamment précis pour convaincre même des oreilles expertes (Rim'k, Booba l'ont validé avant de savoir).** Les patterns sont donc réels et extractibles.

## 1. STRUCTURE TYPE

### Modèle dominant (cloud/sad rap FR TikTok, durée cible : 1:50 – 2:30)

```
[Intro vocale]       4–6 syllabes / vocalise seule (mmh, hm, ah)     ~5–10 sec
[Couplet 1]          6–8 lignes, 8–12 syllabes/ligne                  ~30–40 sec
[Hook / Refrain 1]   4 lignes, répété 2×                              ~20–25 sec
[Couplet 2]          4–6 lignes (plus court que couplet 1)            ~20–30 sec
[Hook / Refrain 2]   Identique ou légèrement varié, répété 2–4×       ~20–30 sec
[Outro / Fade]       Hook en demi-voix ou vocalise seule              ~10–15 sec
```

**Durée totale visée : 1:50 – 2:20.** Le format <2:30 est non négociable pour l'algorithme TikTok (clip extractible à 15 sec, écoute complète favorisée par Spotify).

### Exemples concrets

| Chanson | Structure réelle | Durée estimée |
|---|---|---|
| Willylancien — *Tempête* | Intro vocalise → C1 (6L) → Hook x2 → C2 (4L) → Hook x4 → Fade | ~2:00 |
| Willylancien — *Magique* | C1 (8L) → Hook (4L) x2 → C2 (7L) → Hook x2 → Outro (2L) | ~2:10 |
| Willylancien — *Tunnel* | Intro hum → C1 (6L) → Hook (4L) x2 → C2 (4L) → C3 (4L) → Hook x4 | ~2:15 |
| Paquetá — *Besoin d'air* | Intro hm x3 → C1 (16L long) → Hook x2 → C2 (8L) → Bridge (6L) → C3 (8L) → Hook x3 | ~2:30 |

**Insight structurel clé :** le hook arrive systématiquement avant la 45e seconde. Les intros longues ont disparu. Le refrain doit être reconnaissable dès la première écoute — pas de montée progressive.

## 2. CONSTRUCTION DU HOOK

### Les 4 composantes du hook cloud/sad rap FR

**A. Le titre dans le refrain**
Le mot/titre de la chanson est prononcé dans le hook, souvent en ouverture ou en fin de ligne :
- *Magique* → "J'ai de la purple, elle est **magique**"
- *Tempête* → "J'ai traversé des **tempêtes**"
- *Tunnel* → "Je vois le bout du **tunnel**"

**B. La phrase-état** (déclaration d'une condition, pas d'une action)
Le hook n'est pas narratif — il énonce un ÉTAT émotionnel ou situationnel :
- État de dépassement : "j'ai traversé / maintenant ça va"
- État de manque : "elle a besoin d'aide / moi j'ai besoin d'air"
- État suspendu : "t'es où ?" (question sans réponse = tension ouverte)

**C. La tension non résolue**
Les meilleurs hooks TikTok ne résolvent PAS le problème — ils le posent ou le laissent ouvert. *Besoin d'air* de Paquetá en est l'exemple parfait : le hook oppose "elle a besoin d'aide" à "moi je lui dis pas quand j'ai besoin d'air" → antithèse, aucune résolution, l'auditeur revient.

**D. Le nombre de répétitions**
- Hook minimal : 2 répétitions (première occurrence)
- Hook maximal en fin de morceau : 4–6 répétitions (fade progressif)
- Règle empirique : **le titre de la chanson est prononcé au minimum 6–10 fois** dans le morceau entier.

## 3. LA LIGNE QUOTABLE (caption/story)

### Ce qu'elle est
Une ligne isolée qui fonctionne hors contexte musical — elle se copie-colle dans une story Instagram, une caption TikTok, ou un tweet. Elle doit faire sens seule, en 8–14 mots.

### Les 5 formes qui reviennent

**Forme 1 — L'antithèse courte**
Deux réalités opposées dans la même ligne, reliées par "mais", "et pourtant", "alors que" :
> *Structure :* [état A négatif] + connecteur + [état B positif/neutre]
> *Exemple pattern :* "J'avais tout perdu mais j'ai retrouvé quelque chose"

**Forme 2 — La paradoxe-routine**
Une action banale du quotidien révèle une douleur profonde :
> *Structure :* [geste ordinaire] + [révélation émotionnelle contradictoire]
> *Exemple pattern :* "Je ris quand même / le matin je mens que ça va"
> *(inspiré de PNL/Ademo : "Je vois le soleil se lever et se coucher / je mens en disant ça va")*

**Forme 3 — L'image sensorielle concrète**
Un détail physique/sensoriel porte toute l'émotion — pas d'explication :
> *Structure :* [objet/sensation physique] = [métaphore émotionnelle implicite]
> *Exemple pattern :* "Yeux couleur espoir, cœur couleur nuit" *(d'après Paquetá)*

**Forme 4 — La question sans réponse**
Une question rhétorique ou directe adressée à l'absent(e), jamais résolue dans le morceau :
> *Structure :* "T'es où [maintenant/ce soir/quand ça va pas] ?"
> *(OMBRE2RUE utilise le titre entier comme ligne quotable)*

**Forme 5 — Le constat minimal brutal**
Phrase ultra-courte, sans métaphore, qui dit l'évidence avec brutalité :
> *Structure :* Sujet + verbe + attribut. Maximum 6 mots.
> *Exemple pattern :* "Je m'ennuie de toi" / "Demain c'est vide"

## 4. NIVEAU DE LANGUE, LONGUEUR DES LIGNES, DENSITÉ

### Niveau de langue : entre CM2 et 3e
- **Vocabulaire cible : B1** — compris par n'importe quel ado de 13 ans.
- Argot présent mais **limité à 1–2 mots par ligne max** : niya, tess, go, miskine, nia, khos, barrer.
- Pas de référence culturelle qui exclurait une partie du public.
- Phrases simples, sujet-verbe-complément dominant.

### Longueur des lignes
- Couplet : **8–12 syllabes** (conversationnel, pas de flow technique dense)
- Hook : **6–10 syllabes** par ligne (plus court = plus mémorisable)
- Ligne quotable : **6–14 mots** maximum (doit tenir dans une caption)

### Densité
Faible à moyenne. Le cloud/sad rap FR **évite la surcharge** — pas de jeu de mots complexe toutes les 2 lignes. Une image forte tous les 4–6 lignes suffit. Les lignes "de remplissage" existent (transition narrative) et c'est voulu.

---

## 5. LES VOCALISES

### Placement
- **Intro** : vocalise seule (hm, mmh, ah) sur 2–4 mesures. Sert d'accroche émotionnelle avant les paroles.
- **Transitions couplet → hook** : une vocalise ou interjection ("yeah", "hm", "oh") en ponctuation.
- **Fin de ligne dans le hook** : vocalise de soutien mélodique après le dernier mot.
- **Outro / fade** : hook chanté a cappella ou avec vocalise dominante.

### Combien
Willylancien *Tempête* : "mmh" recensé ~8 fois dans le morceau entier (1 toutes les ~15 sec).
Paquetá *Besoin d'air* : intro "Hmm" x3 + interjections mid-verse.
Règle pratique : **1 vocalise toutes les 2–3 lignes dans le hook, 1 toutes les 4–6 dans le couplet.**

## 6. THÈMES

### Classement par fréquence / efficacité TikTok

| Rang | Thème | Pourquoi ça marche sur TikTok |
|---|---|---|
| 1 | **Manque / absence** | Se colle en caption story "quand quelqu'un te manque" |
| 2 | **Résilience après l'échec** | Motivation + mélancolie = combo émotionnel fort |
| 3 | **Communication impossible** | "je peux pas le/la dire" → frustration universelle |
| 4 | **Nuit / solitude nocturne** | Audio utilisé sur les posts "3h du mat" |
| 5 | **Survie + ascension** | Tunnel, tempête = métaphore vie quartier → succès |
| 6 | **Amour toxique / dépendance** | Purple/weed comme métaphore relation |
| 7 | **Introspection floue** | Pas besoin de comprendre tout pour ressentir |

**Thèmes à éviter** (over-saturés ou pas TikTok) : argent/flex pur, violence explicite, boasting technique.

---

## 7. RATIO CHANTÉ / RAPPÉ

Le cloud/sad rap FR TikTok est **majoritairement chanté ou semi-chanté** :

| Zone | Ratio chanté | Ratio rappé |
|---|---|---|
| Hook/refrain | 80–100% chanté | 0–20% |
| Couplet | 40–60% chanté | 40–60% rappé |
| Vocalises | 100% chanté | — |
| **Global** | **~65% chanté** | **~35% rappé** |

L'auto-tune léger à modéré est quasi-systématique. Le flow "parlé-chanté" (entre rap et R&B) est la norme, pas l'exception. Les couplets rappés gardent une mélodie implicite — on n'est jamais dans le rap technique pur.

## 8. PRODUCTION (contexte pour les paroles)

- BPM : 70–100 (lent, planant)
- Sons dominants : piano simplifié, reverb heavy, hi-hats distants, pad atmosphérique
- L'espace dans le son appelle des paroles espacées — **pas de flow dense, des pauses respiratoires** visibles dans le texte
- Durée totale EP : 12 min pour 5 titres (Willylancien) = 2:24 de moyenne

## 9. TEMPLATES — 5 HOOKS PRÊTS À REMPLIR

> **Mode d'emploi** : remplacer les crochets [ ] par votre contenu. Le titre de la chanson doit apparaître dans au moins une ligne du hook.

---

**HOOK TEMPLATE #1 — L'Antithèse État**
*(pattern : traversé X dur → maintenant Y, le titre = X)*
```
J'ai traversé [NOM_DU_TITRE], (mmh)
Maintenant [état positif ou neutre]
J'disais [mensonge social] c'était [image]
Mais maintenant [vérité]
```
*Exemple de structure remplie :*
"J'ai traversé [l'orage] / Maintenant je respire / J'disais 'ça va' c'était une façade / Mais maintenant je vois clair"

---

**HOOK TEMPLATE #2 — L'Antithèse Elle/Moi**
*(pattern : besoin A de l'autre ≠ besoin B de moi, tension jamais résolue)*
```
[Elle/Il] a besoin de [X]
[Elle/Il] a besoin de [X]  ← répétition exacte
Mais moi je lui dis pas quand j'ai besoin de [TITRE/Y]
```
*Le titre de la chanson = le besoin non dit.*

---

**HOOK TEMPLATE #3 — La Question Ouverte**
*(pattern : titre = question adressée à l'absent(e), répétée 3–4 fois)*
```
[TITRE] ? (hm)
[TITRE] ?
Dis-moi [TITRE]
[TITRE]...
```
*Chaque répétition avec une intonation différente (montante, descendante, plaintive).*

---

**HOOK TEMPLATE #4 — La Déclaration Métaphore-Titre**
*(pattern : objet concret + adjectif chargé, titre = l'adjectif)*
```
J'ai [objet concret], [il/elle] est [TITRE]
[Il/Elle] m'évite [conséquence négative évitée], une fin [adjectif dramatique]
Quand [situation limite], je [réaction]
[TITRE] (x2)
```
*L'adjectif = le titre = le mot-clé émotionnel.*

---

**HOOK TEMPLATE #5 — La Déclaration Minimale Répétée**
*(pattern : phrase ultra-courte, 4–6 mots, répétée avec vocalise)*
```
[TITRE en 3–5 mots]  (mmh)
[TITRE en 3–5 mots]  (yeah)
[Variation de 2 mots max]
[TITRE]... [fade/vocalise]
```
*Exemple abstrait : "Demain c'est vide (mmh) / Demain c'est vide (hm) / Rien devant / Demain c'est vide..."*

---

## 10. TEMPLATES — 5 LIGNES QUOTABLES PRÊTES À REMPLIR

> **Mode d'emploi** : formules vides, pas de contenu copié. La ligne doit fonctionner hors contexte musical.

---

**QUOTABLE #1 — Antithèse en deux temps**
```
[J'avais / J'ai] [chose perdue ou dure], [connecteur], [chose gardée ou retrouvée]
```
*Règle : les deux éléments doivent surprendre ensemble. L'un doit contredire l'attente de l'autre.*

---

**QUOTABLE #2 — Geste ordinaire + révélation cachée**
```
Je [action banale du quotidien], je mens en disant [état affiché]
```
*Ex pattern : "Je souris au réveil, je mens en disant ça va"*

---

**QUOTABLE #3 — Image sensorielle double**
```
[Partie du corps] couleur [abstraction positive], [autre partie] couleur [abstraction négative]
```
*Ex pattern : "Yeux couleur espoir, cœur couleur nuit" / "Voix couleur soleil, âme couleur cendre"*

---

**QUOTABLE #4 — Question adressée**
```
T'es [où / comment / avec qui] quand [situation émotionnelle précise] ?
```
*La situation doit être universelle (3h du mat, quand ça va pas, quand je pense à rien).*

---

**QUOTABLE #5 — Constat minimal brutal**
```
[Sujet court] + [verbe simple] + [vide / rien / trop / plus]
```
*4–6 mots maximum. Pas de métaphore. L'efficacité vient de la nudité.
Ex patterns : "Demain c'est vide" / "Je t'entends encore" / "Tu manques trop" / "C'est plus pareil"*

## RÉSUMÉ FINAL

| Dimension | Pattern extrait |
|---|---|
| Durée | 1:50 – 2:20 (jamais plus de 2:30) |
| Structure | Intro vocalise → C1 (6–8L) → Hook x2 → C2 (4–6L) → Hook x4 → Fade |
| Hook | Titre dans le hook, phrase-état, tension non résolue, 4 lignes répétées 2–6× |
| Ligne quotable | Antithèse, paradoxe-routine, image sensorielle double, ou constat brutal ≤6 mots |
| Langue | B1 / CM2-3e, 1–2 mots d'argot par ligne max, 8–12 syllabes/ligne |
| Vocalises | Intro + transitions + fin de hook, ~1 toutes les 3 lignes dans le hook |
| Thèmes top | Manque, résilience, communication impossible, solitude nocturne |
| Ratio | 65% chanté / 35% rappé, auto-tune léger systématique |
