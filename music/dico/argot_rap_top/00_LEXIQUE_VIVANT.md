## 🛠️ TECHNIQUES D'ÉCRITURE (cheat-sheet, qui fait quoi)
- **Ellipse du déterminant** (Booba) : "j'ai mis bouteille sur table" → punch sec.
- **Comparaison "comme" en rafale** (Freeze) : enchaîner les "comme un..." → signature hypnotique.
- **Rimes équivoques multisyllabiques** (Nekfeu, Alpha Wann) : "banquise fond / banques ils s'font" → double sens phonétique.
- **Métaphore filée sur tout le morceau** (Lomepal, Laylow) : un seul champ lexical (ex: informatique = amour) du début à la fin.
- **Champ lexical décalé appliqué à l'intime** (Laylow) : médecine/cosmos/jeu vidéo pour parler de soi.
- **Retournement d'expression figée** (Dinos) : prendre un proverbe et le tordre.
- **Antithèse force/fragilité** (Damso, Hamza) : flexer + avouer la faille dans la même phrase.
- **Accumulation/zoomorphisme** (Kaaris) : empiler images animales/brutes.
- **Narration cinématographique** (SCH/JVLIVS) : le morceau = une scène de film.
- **Ego-trip second degré** (Sneazzy, Vald) : l'arrogance comme personnage assumé.
- **Setup / punch** : mise en place banale → chute qui retourne.

## 🌫️ POUR RODT (cloud/émergents — fichier 07)
- **5 pôles du créneau** : absence · nuit/froid · douleur douce · "la bulle" · résilience ironique.
- **Formule hook gagnante** : titre = 1 mot = un ÉTAT, répété (T'es où / Magique / Besoin d'air).
- **Procédés** : autotune fondu, format vignette (<2min), hook = titre = état, vocalises, simplicité.
- L'avantage RODT déjà identifié : **humain vrai** (pas IA) → l'émotion sincère + le grain "breathy/raw".
