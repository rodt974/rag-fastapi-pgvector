# RODT — Fiche d'identité / Signature

À respecter dans CHAQUE son. C'est ce qui rend RODT reconnaissable d'un morceau à l'autre.

## Concept
RODT = l'appel masqué d'un **numéro inconnu**. Artiste anonyme, masqué, cloud rap planant.
Univers : masqué, solitude, nuit, cité, beuh/élévation, mystère, anonymat.

## Les 5 marqueurs (obligatoires)
1. **Voix** : grave / rauque (« OUTRE-TOMBE »), pas d'autotune céleste. Anti-ralenti (BPM clair + 808).
2. **Tag d'intro** : « Numéro inconnu » (voix froide/robotique au tout début).
3. **Phrase signature** : « Sous l'masque, j'souris jamais » — placée dans chaque son (hook ou fin de couplet).
4. **Ad-lib** : « bip... bip... » (tonalité de téléphone) — en intro et/ou entre les sections.
5. **Titre** : un numéro / code (ex : 404, 7, 01, #INCONNU).

## À garder
- Vocalises cloud planantes (Hannn... héééé... ohhh...) en plus de l'ad-lib bip.
- Double-sens / punch du dico, mais dosés (pas de surcharge « poème »).
- Argot cité réel, sans en faire trop.
- Dualité possible (rêve/cauchemar) mais SANS cloner PNL.

## À éviter
- Autotune mélodique céleste à la PNL (on n'est pas un clone).
- Reprendre des bars d'artistes existants (verbatim = interdit).
- Prompts qui font partir l'instru en électro (voir note prod).

## Note prod (honnête)
- Le **« Numéro inconnu »** robotique et le **« bip... bip... »** : Suno ne les génère pas de façon fiable.
  Le plus propre = les **ajouter en post** (CapCut/montage) : un SFX de tonalité + une voix TTS « numéro inconnu » en intro.
  Dans Suno on peut tenter les balises [phone dial tone] / [busy tone] / [robotic voice: numéro inconnu] mais c'est aléatoire.

## Style prompt de base (anti-électro)
french rap, melodic cloud rap, trap beat, deep 808 bass, crisp hi-hats, deep raspy baritone vocals, dark melancholic, spacious, slow laid-back flow, half-time 130 BPM, masked mystery
Exclude : EDM, electro, house, future bass, synthwave, dance
