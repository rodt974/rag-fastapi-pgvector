# RODT.MASQUE — LE son final (Round 2, synthèse + arbitrage du débat)

DÉCISION : pivot de "PERSONNE" vers "MASQUE", après le réquisitoire de l'avocat du diable.
Raisons : 1) mono-concept (pas une synthèse molle multi-axes) ; 2) "masque" = le persona, territoire libre
dans le cluster ; 3) angle INCOPIABLE = un HUMAIN vrai qui saigne, dans un marché saturé d'IA anonymes ;
4) énergie TRANSITION (le feu sous le calme), pas la tristesse passive saturée ; 5) on DROP le cliché mort
"cent contacts personne répond".
Hook : "sous l'masque" martelé (règle des 7 : 1 mot-ancre x4, <10 syll, tension non résolue, vocab simple, boucle vocalise).
Prod : 140 BPM half-time, 808 qui sanglote, autotune "breathy, slightly raw, human imperfection" (pour sortir du son robotique IA).
