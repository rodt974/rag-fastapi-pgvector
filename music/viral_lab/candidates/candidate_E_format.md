# CANDIDATE E — FORMAT TIKTOK

---

## 1. TITRE + CONCEPT

**Titre : "SOUS L'MASQUE"**

Concept : Un couplet planant, cloud rap mélancolique, puis une cassure brutale en double-time mid-morceau — le masque "craque" et le flow explose pendant 8 secondes, avant de retomber dans le silence. TikTok utilise l'instant de la cassure comme point d'entrée. Le son se boucle sur la vocalise finale "hannn..." — parfait pour les vidéos "POV : tu retires le masque".

---

## 2. POURQUOI CA PERCE — MECANIQUE TIKTOK

- **0-3s : hook immédiat** — première ligne chantée avec autotune, six syllabes, une vocalise. Le scroll s'arrête.
- **Le MOMENT (environ 0:38 / section [Verse] bar 5)** : passage calme -> rafale double-time -> retour silence. C'est LE timestamp que TikTok va clipper. Effet "wait for it" garanti : l'auditeur ralentit la vidéo, la rejoue.
- **Boucle** : la vocalise finale "hannn..." se fond dans l'intro. Suno génère une boucle naturelle — idéale pour les sons réutilisés.
- **Réutilisabilité** : "sous l'masque j'souris jamais" est une phrase-concept. Les utilisateurs font leur propre "reveal", leurs "POV cité", leurs "lore drops". Le masque de RODT est un prop physique TikTok en soi.
- **Durée cible Suno** : 1:45-2:00. Optimal pour TikTok/Reels (pas de skip à 30s, pas de drop d'attention à 60s).

---

## 3. LE HOOK (0-3s) + LE MOMENT

### HOOK IMMEDIAT — 0 à 3 secondes

> **"Sous l'masque j'souris jamais... hannn..."**

Une seule ligne, autotune pleureur sur "jamais", vocalise "hannn" qui descend. Pas de beat pendant 1,5s — juste la voix dans le reverb. Puis le kick tombe.

Pourquoi ca marche : contraste silence / kick = sursaut. Six syllabes mémorisables. Le masque comme visuel = image mentale instantanée. La vocalise = son réutilisable.

---

### LE MOMENT — "WAIT FOR IT"

**Timestamp : ~0:35-0:45 (section [Verse], deuxième moitié)**

Mécanique :
1. Couplet planant, flow atmosphérique, 2-3 syllabes par temps, reverb profond, autotune.
2. **SILENCE COMPLET — 1 beat.**
3. **[double-time, rapid flow]** : rafale de 8 barres en débit maximal, le 808 monte, les hi-hats s'emballent. Les mots s'entassent — "j'ai tout perdu j'ai tout refait j'ai tout brûlé j'recommence les gens me voient plus mais moi j'me vois".
4. Beat coupe net. Retour au reverb planant de l'intro. Vocalise "ouhhhh...".

C'est le clip que TikTok va découper : 3s avant le silence + 8s de rafale + retour calme = 11 secondes parfaites.

## 6. LES 8 PREMIERES SECONDES + LE MOMENT "WAIT FOR IT"

### 8 premières secondes :

| Temps | Ce qui se passe |
|-------|----------------|
| 0s | Silence total. Pas de beat. |
| 0,5s | Voix seule avec reverb profond : *"Sous l'masque j'souris jamais..."* |
| 2s | Vocalise autotune descendante : *"hannn..."* |
| 3s | **Kick 808 qui tombe.** Basse qui entre. L'écran vibre. |
| 4-8s | Hook mélodique — flow half-time planant, première ligne du refrain répétée. |

Effet sur TikTok : le silence initial force l'utilisateur à monter le son. Le kick à 3s = sursaut. L'algo détecte le premier pic d'engagement à 3-4s — exactement là.

---

### LE MOMENT "WAIT FOR IT" — ~0:35 :

Avant : flow atmosphérique, 2 syllabes par temps, voix qui flotte dans la reverb, tout est calme. La barre se coupe sur "j'ai pris la hauteur et—".

**SILENCE. 1 beat. Rien.**

Puis : [double-time, rapid flow] — le 808 monte d'une octave, hi-hats en triplets, et RODT lâche 8 barres en rafale. Débit x3, chaque syllabe compressée, les rimes s'enchaînent sans respiration. Le texte raconte la même chose que le couplet planant — mais en accéléré, comme si le masque craquait et que tout sortait d'un coup.

Retour au calme. Hook. Le contraste est total.

**Ce timestamp sera le point d'entrée de 80% des vidéos TikTok utilisant ce son.**
