## 1. BPM — LOGIQUE HALF-TIME EXPLIQUÉE

### Le chiffre cible : 140 BPM réel — 70 BPM perçu

Le cluster qui perce (Paquetá "Besoin d'air" ~2,2M streams, Willylancien "Magique" #1 Deezer, Zemi "la même" 1:42 viral) tourne sur une logique trap half-time :

| Paramètre | Valeur | Pourquoi |
|---|---|---|
| BPM affiché dans Suno | 140 | Donne la grille hi-hat caractéristique |
| BPM perçu à l'oreille | 70 | Le flow se pose sur les temps forts, pas sur chaque noire |
| Snare / clap | Temps 3 (pas le 2) | Signature drill mélodique FR — lourdeur pesante |
| 808 | Longue, tenue après le kick | Donne le "souffle" émotionnel |
| Hi-hat | Doubles ou triples (1/16e) | Crée la tension sans saturer |

### Variante afro-hybride (façon Willylancien)
- BPM : 105 BPM réel / 52 perçu (mid-tempo afrobeat)
- Le flow suit le groove syncopé, pas les temps droits
- Percussions afro sur les contretemps (off-beat)

### Règle d'or half-time pour Suno
Rapper "comme si c'était du 70 BPM" sur un beat à 140 : chaque syllabe forte pèse le double. Les silences entre les phrases valent autant que les mots.

## 2. GRAIN DE VOIX — AUTOTUNE ET TEXTURE

### Le son du cluster (données convergentes multi-artistes)

**Willylancien** : "Voix lisse, légèrement robotique, se fond dans l'instru avec une précision troublante" — autotune **épais et homogène**, pas d'aspérités, sons Suno caractéristiques.

**Paquetá** : Ad-libs atmosphériques en ouverture ("Hmm hmm non non non"), voix introspective, autotune modéré sur les fins de syllabes, **round et doux**.

**OMBRE2RUE / franklin ctoi** : Cluster identique, grain léger mais omniprésent, **jamais criard**.

### Recommandation pour RODT dans Suno

| Paramètre vocal | Réglage cible |
|---|---|
| Autotune | Épais (heavy), mais lisse — pas de glitch artificiel |
| Tessiture | Voix grave-médium (baryton), pas de ténor |
| Texture | Légèrement rauque sur les couplets, plus lisse sur le hook |
| Reverb | Longue queue (room large), donne l'impression de nuit vide |
| Adlibs | "Hmm", "ouais", "non" — planants, pas agressifs |
| Ton émotionnel | Mélancolique, **blessé mais posé** — jamais crié |

**Différence RODT vs IA pure** : Une légère imperfection vocale (grain, souffle audible) est l'avantage humain. Dans Suno, demander explicitement "raw, slightly imperfect vocal delivery, breathy" pour se démarquer des sons trop polished.

## 3. INSTRUMENTS ET AMBIANCE — LA PALETTE SON

### Éléments obligatoires (présents dans tout le cluster)

| Instrument | Rôle | Comment l'utiliser |
|---|---|---|
| **808** | Colonne vertébrale émotionnelle | Longue, tenue, légèrement déformée (pitch down) — doit "sangloter" |
| **Piano** | Mélodie principale | Simple, 4-6 notes max, mode mineur (la mineur ou ré mineur), quelques fausses notes voulues |
| **Hi-hat** | Texture rythmique | En 1/16e ou triplets, vélocité variable (pas robotique) |
| **Nappe (pad)** | Atmosphère | Synthé éthéré, attaque lente, longue queue de reverb |
| **Kick** | Structure | Lourd, sur le temps 1 principalement, rare sur le 3 |
| **Snare/clap** | Marqueur | Sur le temps 3 (drill style) — pas le 2 |

### Éléments différenciants (ajouter pour plus de caractère)

| Instrument | Effet | Usage |
|---|---|---|
| **Cloches / glockenspiel** | Mélodie froide et cristalline | Intro et bridge, 2-3 notes |
| **String (cordes)** | Tension émotionnelle | Montée sur le pré-refrain, sortie sur l'outro |
| **Sample vocal** | Mystère / humanité | Voix féminine lointaine, filtrée, coupée |
| **Crackle vinyle** | Lo-fi, chaleur | Léger, en dessous de tout le reste |

### Ambiance cible en 3 mots
**Nuit. Vide. Planant.**

Références sonores : Paquetá "Besoin d'air", Willylancien "Magique", OMBRE2RUE "Nuit blanche"

## 4. STRUCTURE IDÉALE — DURÉE ~2:00

### Architecture minute par minute

```
[0:00 - 0:06] INTRO SILENCE + ACCROCHE
→ 1-2 mesures de nappe seule, pas de kick
→ Voix entre immédiatement (pas d'intro instrumentale longue)
→ Première ligne = la punchline-accroche
→ OBJECTIF : stopper le scroll en 3 secondes
→ Formule : "sous l'masque j'souris jamais..." (paradoxe immédiat)

[0:06 - 0:35] COUPLET 1 — flow planant (8 barres)
→ Flow half-time mélodique, 1 syllabe forte par temps perçu
→ Thème : solitude + la nuit + personne ne répond
→ "cent contacts dans l'phone, personne répond"
→ Aéré, silences entre les phrases

[0:35 - 0:50] LE MOMENT — switch double-time (4 barres)
→ Le beat peut rester identique mais le flow double sa densité
→ OU : légère montée de l'instru (cordes, hi-hat plus serré)
→ C'est ici que la tension émotionnelle éclate
→ Peut contenir la seule vraie punchline du son
→ "sous l'masque j'saigne en or" — une seule fois, ici

[0:50 - 1:10] HOOK x2 — ancrage earworm
→ 4-6 mots max par ligne
→ Répété 2 fois d'affilée (structure : AABB ou AA)
→ La mélodie vocale est simple, 3-4 notes
→ Exemple : "sous l'masque j'souris jamais / c'est l'seul endroit où j'mens pas"
→ Ce sont les 20 secondes TikTok

[1:10 - 1:35] COUPLET 2 — plus lourd
→ Plus personnel, plus brisé que le couplet 1
→ Le beat peut légèrement s'enrichir (strings entrent)
→ Thème : l'absence de l'autre / "t'es où quand j'ai besoin d'air"
→ 8 barres, même densité que le couplet 1

[1:35 - 1:55] HOOK x2 — reprise + variation
→ Même hook, mais voix légèrement différente (harmonie, ad-lib en dessous)
→ Dernier hook peut s'éteindre progressivement (fade)

[1:55 - 2:00] OUTRO — silence/nappe
→ 2-4 mesures de nappe seule
→ Optionnel : murmure ou ad-lib final
→ Laisse l'auditeur dans l'ambiance, envie de relancer
```

### Durée exacte recommandée : 1:55 à 2:10

Ni plus (perd l'algo TikTok), ni moins (semble inachevé sur Spotify).

## 6. 5 ASTUCES SUNO POUR CE SON

### Astuce 1 — Utiliser les balises de section [Verse]/[Hook] avec indicateurs émotionnels
```
[Verse - slow, melancholic, half-time flow]
[Pre-Hook - building tension]
[Hook - repeated 2x, simple melody]
[Bridge - double-time moment, emotional peak]
```
Suno respecte mieux la structure quand les balises précisent l'énergie attendue, pas seulement le nom de section.

---

### Astuce 2 — Le paramètre "Weirdness" : rester sous 30%
Pour ce son, le weirdness doit rester **bas (10-25%)**. Les sons viraux du cluster sont calibrés, prévisibles, pas expérimentaux. Un weirdness élevé casse l'earworm et rend le hook moins mémorisable. Tester à 15% comme point de départ.

---

### Astuce 3 — Exclude pour éviter les dérives
Dans le champ d'exclusion (ou en ajoutant "no X" dans le style prompt) :
```
no upbeat, no happy, no major key, no fast rap, no aggressive delivery, no shouting, no heavy metal, no jazz, no chorus pop, no female vocals (unless backup)
```
Suno peut dériver vers le festif ou le pop si non cadré. Ces exclusions maintiennent le son dans l'ambiance nocturne-mélancolique.

---

### Astuce 4 — Forcer l'intro courte avec balise [Intro - 4 bars only]
Le défaut de Suno est de générer des intros instrumentales longues (8-16 mesures). Pour stopper le scroll :
```
[Intro - 4 bars, voice enters immediately, no drums for first 2 bars]
```
La voix doit entrer dans les 6 premières secondes. Cette balise + instruction forcent Suno à placer la voix en avant dès le début.

---

### Astuce 5 — Régénérer uniquement le hook, garder les couplets
Quand un couplet sonne bien mais le hook est trop générique (défaut fréquent de Suno) : utiliser la fonction "Continue from" ou régénérer seulement la section hook. Tester 5-8 variantes du hook sur la même base instrumentale, puis choisir celle dont la mélodie vocale est la plus répétable (test : la chantonner 10 minutes après).

| Weirdness Suno | 10-25% |
| Prompt style | Voir A/B/C selon variante |

### Ce que RODT a que l'IA n'a pas
Le cluster est saturé de sons Suno robotiques. L'avantage de RODT : une vraie histoire émotionnelle derrière le masque. Dans Suno, demander "breathy, slightly raw, human imperfection" produit un grain plus proche de l'humain — et c'est exactement ce que l'auditeur ressent sans pouvoir nommer.
