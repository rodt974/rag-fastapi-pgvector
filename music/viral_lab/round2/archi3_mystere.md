## TITRE

**MASQUE**

Un mot. Un objet. Une question. Le titre EST le mystère — pas une explication, une image que les gens projettent.

---

## L'ANGLE QUI FAIT SPÉCULER

### Le paradoxe central : "Je me cache pour être plus réel"

Le marché 2026 est saturé d'IA anonymes sans visage, sans histoire, sans douleur vraie.
RODT a un avantage unique et concret : **c'est un humain sous le masque**.

L'angle n'est pas "je suis mystérieux" — c'est **"derrière ce masque y'a quelqu'un qui saigne pour de vrai"**.

Ce n'est pas la même chose. L'un est une posture marketing. L'autre est une vérité qu'on sent dans la voix.

### Le mécanisme de débat

Franklin ctoi a mis sa question d'identité dans le **titre** : "Qui est franklin ?"
RODT fait un pas de plus : il met le mot-objet du mystère dans le titre, **le martèle dans le hook**, et laisse la question **sans réponse dans le bridge**.

Résultat : les commentaires s'écrivent seuls.
- "c'est qui derrière le masque ?"
- "y'a forcément quelqu'un de connu là-dessous"
- "c'est une IA ou un vrai ?"
- "pourquoi il enlève jamais le masque ?"

**Réponse de RODT : jamais.** Liker les "c'est qui", ignorer les révélations, laisser les théories vivre.

### La phrase qui polarise (à utiliser en caption TikTok)

> "Le seul rappeur FR qui se cache pas derrière une IA, juste derrière un masque."

Cette phrase crée deux camps :
- Camp A : "respect, y'a un vrai artiste là-dessous"
- Camp B : "comment tu sais que c'est pas une IA ?"

Les deux camps commentent. L'algo avance.

## IDÉE DE FORMAT VIDÉO

### Format principal : "La Main sur le Masque"

**Setup** : RODT assis, lumière basse (une seule source sur le côté), fond sombre. Son visible uniquement de la poitrine vers le haut. Masque toujours en place.

**Action** : Au moment du bridge ("un soir j'enlèverai l'masque"), la main monte vers le masque. Lentement. S'arrête. La main retombe. Cut.

**Texte à l'écran** : "pas ce soir" — fade out.

**Pourquoi ça marche :** C'est le format que tout le monde va partager en mode "MAIS POURQUOI IL L'ENLEVE PAS". La frustration = engagement = commentaire = algo.

### Format secondaire : "Proof of Human"

**Setup** : Plan serré sur les mains de RODT. Stylo sur papier. Il écrit les paroles à la main. La caméra monte progressivement vers le visage. Masque. Coupe avant tout reveal.

**Caption** : *"les IA écrivent pas à la main"*

**Pourquoi ça marche :** Répond directement au débat "IA ou humain ?" sans jamais rien confirmer. Les gens qui défendent ("c'est un humain, vous voyez les mains") génèrent autant de contenu que les sceptiques.

### Format tertiaire : "Live Session Masquée"

Reprendre exactement ce que fait franklin ctoi avec ses live sessions, mais en gardant le masque. Version stripped du son — juste voix + piano ou guitare simple. Montre la technique vocale (preuve d'humain) sans révéler l'identité.

## RÉSUMÉ FINAL

**MASQUE** est l'architecture virale pensée pour déclencher une seule question en commentaire : "c'est qui ?"

Le mot-titre est martelé 4 fois à chaque hook, ancré comme un objet physique pas comme un concept flou. Chaque occurrence du mot dans le hook apporte une nuance nouvelle : l'existence derrière le masque, l'anonymat assumé, la douleur réelle, l'impermanence. Pas de fausse gloire, pas d'ego prématuré — "personne me connaît encore" est une ligne de réalisme débutant qui désarme la méfiance et renforce l'authenticité.

L'avantage différenciant de RODT dans un marché saturé d'IA anonymes est joué frontalement : "j'suis pas une IA, j'suis quelqu'un qui ose pas encore montrer sa tête". Cette ligne fait deux choses simultanément — elle pose l'humanité de l'artiste ET maintient le mystère sur l'identité réelle. Impossible pour une IA de vendre cette vérité-là de manière crédible.

Le Pont double-time est le clip TikTok. Le Bridge "pas ce soir" est le format vidéo. L'Outro "vous saurez jamais... ou peut-être si" est la caption.

Structure cible : ~2:10. Un seul objectif : faire commenter "c'est qui derrière le masque ?"
